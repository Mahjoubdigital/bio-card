📋 Cómo publicar los cambios

  1. Edita los campos y pulsa Guardar borrador
  2. Haz clic en Ver cambios para previsualizar
  3. Si todo está bien, pulsa Exportar data.js
  4. Sustituye el archivo data.js en tu repositorio de GitHub
  5. Haz git commit y git push
  6. Vercel redeployará automáticamente ✅
